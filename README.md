# AI Study Companion - Module 1

## Project Overview
AI Study Companion is a web-based application that helps students manage their study activities. This repository contains the Module 1 implementation of the project.

## Technologies Used
- Node.js
- Express.js
- Firebase

## Module 1 Features
- Project setup using Node.js
- Express.js server configuration
- Firebase integration
- Basic backend structure
- REST API setup

## Project Structure
```
AI-Study-Companion-Module1
│── lib/
│   └── firebase.ts
│── server.ts
│── package.json
│── package-lock.json
│── README.md
```

2. Install dependencies:
```bash
npm install
```

3. Start the server:
```bash
npm run dev
```
